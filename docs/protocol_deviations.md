# Protocol Deviations and Clarifications

## Certificate quantization wording

- Protocol: `protocols/certificate_extension.yaml`
- Discovered: 2026-07-16, after the frozen run
- Scope: implementation wording, not the population, lower method, scale,
  closure rule, or reported metric

The frozen `rounding` field says that nonnegative LP charges are rounded
upward and a group deficit is repaired. The implemented method in
`_apportion_exact` first normalizes each group's nonnegative floating shares,
floors their ideal integer-unit allocations, and gives the remaining units to
the largest fractional remainders with deterministic index tie breaking.
Thus every group distributes exactly `weight * 1_000_000_000` nonnegative
integer units.

The frozen protocol file is retained unchanged. All reported certificate rows
were generated by the implementation just described. The difference can alter
a quantized upper bound only at the certificate-unit rounding level; it cannot
make a certificate unsound because both root and branch verifiers independently
require exact integer charge conservation.
The complete-closure protocol uses the more general phrase “quantized charge”
and does not repeat the inaccurate rounding description.
